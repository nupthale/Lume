# ASCII 表格生成

## 为什么需要这个技能

中英文混排表格的对齐是个经典的坑：一个汉字在等宽字体里占 **2 列**显示宽度，
但 JS 的 `.length` 和 Python 的 `len()` 都按字符数算（汉字 = 1）。
按字符串长度补空格，表格必然歪。本技能的配套脚本按「东亚宽度」精确计算
每个字符的显示宽度，保证对齐。

## 用法（必须用脚本，禁止手工对齐）

1. 把数据组织成 JSON：

```json
{"header": ["名称", "单价（元）", "库存"], "rows": [["机械键盘（青轴）", "299", "42"]]}
```

2. 执行脚本（单引号包住 JSON，数据里不能含单引号）：

```bash
python3 skills/ascii-table/scripts/align.py '{"header":["名称","单价（元）","库存"],"rows":[["机械键盘（青轴）","299","42"]]}'
```

3. 脚本输出对齐好的表格，**原样**呈现给用户，不要自己增删空格。

## 宽度规则（供你理解脚本行为，不要自己实现）

- 东亚宽字符（汉字、全角标点（）、CJK 假名谚文）显示宽度记 2
- 拉丁字母、数字、半角标点记 1
