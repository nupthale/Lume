# SVG 图表绘制规范

统一遵循本规范作图，保证产物风格一致、坐标不越界、数值可读。

**本技能没有配套脚本**：直接由你按下面的规则手写完整 SVG 代码，
不要猜测或尝试运行任何 scripts/ 下的文件。

## 画布与绘图区

- 画布：`viewBox="0 0 640 400"`，背景 `#fafafa`，圆角 8
- 绘图区：x ∈ [70, 610]，y ∈ [40, 340]（四周留白给标题和坐标轴）
- 所有文本 `font-family="system-ui, sans-serif"`

## 柱状图

1. 数据条数 n，柱宽 = 绘图区宽 / (n × 1.6)，柱间距 = 0.6 × 柱宽
2. 数值 → 高度线性映射：`h = (v - v_min) / (v_max - v_min) × 280`；
   常规情况 v_min 取 0，只有强调相对变化时才取数据最小值（并在图下注明）
3. y 轴画 5 条网格线（`#e0e0e0` 虚线 stroke-dasharray="4 4"），
   左侧标注对应数值（font-size 11, fill #888）
4. 柱子颜色 `#4c78a8`，柱顶上方 4px 标注数值（font-size 12, text-anchor middle）
5. x 轴下方标注类目名（font-size 12）；画布顶部居中写标题（font-size 16, 粗体）

## 折线图

- 折线 `#e45756` stroke-width 2；数据点半径 3；线下填充 10% 透明度同色
- x 均分；网格与数值标注规则同柱状图

## 输出要求

1. 写入 `output/` 目录下的 `.svg` 文件（文件名语义化，如 `output/sales.svg`）
2. 向用户报告文件路径，并用文字概括图中 top 项与趋势
